# 《没有 Opus,可以做出圈的 AI 视频吗?》旁白

成片的旁白和字幕,从 `doc.tsx` 提取。时间是每句结束的位置,全片 4:21。

0:00–0:16 没有旁白:输入框里打出问题,17 部片子越翻越快,配开场音乐。

## 01 问题

- `0:19` 最近，用 Opus 这样的顶配模型做的视频，挺出圈的。
- `0:23` 这些片子，如果没有 Opus，还做得出来吗？
- `0:31` 别的模型也会写代码，也讲得清道理。差距最大的地方，往往是审美。
- `0:39` 可审美是什么？是配色，是字体，是镜头什么时候动、什么时候不动。
- `0:46` 那能不能把审美写下来，做成一套风格，让不同的模型都能参考和复用？

## 02 试一下

- `0:54` 我们让 Opus 把审美写成四套风格：一份不到 8000 字节的说明，加一组画好的组件。
- `1:02` 然后交给一个价格低得多的模型：DeepSeek。四套风格，四个它没见过的问题。
- `1:08` 第一套，夜光图解。Opus 的样片，讲闪电从哪儿来。
- `1:19` DeepSeek 换成神经细胞放电的那一瞬。细胞膜、离子、放电曲线，全是它照着风格的规矩自己画的。
- `1:27` 第二套，大地块。Opus 切开一块地，讲雨水去了哪儿。
- `1:36` DeepSeek 换成街道下面埋着什么。它把一条街切开，一层一层往下讲，讲到地铁隧道。
- `1:43` 第三套，铅垂线。Opus 放下一根线，一路沉到海底。
- `1:52` DeepSeek 反过来往上走：大气层有多高。一路爬到一万公里，再退回来，护住我们的，只有细细一条线。
- `2:01` 第四套，光学台。这回是 3D，Opus 用一块棱镜，把白光拆开。
- `2:07` DeepSeek 换成镜头怎么成像，光路是它一条一条算出来的。
- `2:13` 四部片子，模型费一共不到一美元，配音另算。

## 03 老实话

- `2:19` 先说毛病。夜光图解的细胞里，冒出了一排不该有的地平线。
- `2:23` 大地块的管线，中途消失了一幕。
- `2:26` 每种风格只跑了一次，题目也是我们挑的。
- `2:34` 但这只是第一轮的结果。多修几轮，还能继续提升，毕竟 DeepSeek 省钱，修得起。
- `2:39` 但结论已经看得出来：审美可以写下来。
- `2:42` 2D，完全可以。
- `2:45` 2.5D，也可以。
- `2:52` 3D 呢？物体和光路都对，可镜头几乎不动，光也过曝了。
- `2:58` 风格写得下材料，写不下镜头该往哪儿走。3D，还要靠模型底子。
- `3:05` 同一道题，不给风格，它老老实实画了一张 2D 图，讲得还不差。
- `3:10` 给了风格，它才真正做成了 3D，只是还没讲得更清楚。
- `3:18` 再换一道题，特斯拉 Roadster 怎么贴在墙上。不给风格，是一张平面示意图。
- `3:23` 给了风格，车轮和气流都立起来了，这回强了一大截。
- `3:27` 所以 3D 这一块，大家可以多换几个模型，自己试试。

## 04 样式库

- `3:32` 这些风格，就放在 VisoTalk 里。
- `3:41` VisoTalk 是一个做讲解视频的 agent 技能。它的目标，是让更多模型，也能做出顶配的讲解视频。
- `3:45` 它有一座样式库，今天是二十一套风格。
- `3:55` 这就是我们说的，审美，可以写下来。Opus 这样的顶配模型写一次，样式库就多一套，此后每个模型都能用。
- `4:00` 你用什么模型不重要。顶配模型的审美，可以一直攒下去。
